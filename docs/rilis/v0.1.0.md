## Yomi Island 0.1.0 (beta pertama)

Dynamic island Windows bertema neko untuk pembaca manga dan penggemar anime.

- **Pill selalu tampil** di tepi atas layar; hanya bersembunyi untuk game/video layar penuh sungguhan dan mode rapat.
- **Ukuran pill** bisa dipilih (Kecil, Menengah, Sedang) di Pengaturan > Tampilan, lengkap dengan pratinjau.
- **Tab Musik** menampilkan sampul album lagu yang diputar; bila tidak ada, dibuat sampul pengganti otomatis.
- **Suara latar Lo-fi** malam, hujan, dan kafe dengan lagu pilihan.
- Task harian, timer baca, jadwal anime dan update manga, kontrol musik dengan lirik, mode rapat dan mode nonton, jalan otomatis saat Windows mulai, serta pemberitahuan versi baru.

Unduh: `…-setup.exe`. Jika SmartScreen muncul: Informasi lebih lanjut, lalu Tetap jalankan (installer belum bertanda tangan digital).
